# Random Quote Generator ✨

A simple and clean **Random Quote Generator** built with **HTML, CSS, and JavaScript**.
This project generates motivational quotes at random and was built as part of my frontend learning journey.

## Features

* Generates random quotes with a single click
* Clean and simple user interface
* Beginner-friendly JavaScript logic


## Built With

* **HTML** – Structure of the app
* **CSS** – Styling and layout
* **JavaScript** – Logic and DOM manipulation

## What I Learned

* How to manipulate the DOM using JavaScript
* How to work with arrays and objects
* How to handle button click events
* How to structure a small frontend project

This project is open for learning purposes. Suggestions and improvements are welcome.
